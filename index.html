How links & types are decided

The map renders only what you upload — no assumed devices, no invented links. For text configs, only what's literally in the file is extracted; structure comes from config evidence (gateway chain, CDP/LLDP) or directive comments you add, e.g. ! topo-id: sw1 ! topo-type: switch ! topo-uplink: rtr1. A missing uplink shows dashed with ⚠ — never guessed.
